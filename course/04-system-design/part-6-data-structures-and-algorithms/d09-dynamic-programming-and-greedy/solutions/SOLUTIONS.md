# Solutions & Commentary — Module D09: Dynamic Programming and Greedy

## Key Takeaways
- Identify optimal substructure and overlapping subproblems.
- Top-down memoization (`@functools.lru_cache`) vs Bottom-up tabulation (1D/2D DP table).
- Greedy algorithms succeed only when local optimal choices lead to global optimum (e.g. fractional knapsack, interval scheduling).
