# Level 01 — Beginner

**Start here if you have never programmed, or if you have only ever copied and
adapted other people's code.**

This level assumes nothing. Not a terminal, not an editor, not a for loop. It
takes you from "what is a program" to a finished command-line application you
can show someone, in twelve modules.

| | |
|---|---|
| Modules | B01 to B12 |
| Duration | 10 weeks |
| Weekly load | 6 to 8 hours |
| Prerequisite | A computer and the willingness to type things wrong |
| Ends with | A working expense tracker you built in six stages |

## How this level is taught

**Nothing is simplified into something you have to unlearn.** A name is called a
label from the first day, not a box, because the intermediate level will make
that idea precise rather than replace it. Type hints appear in Module B06, not
as an advanced extra. Narrow exception handling is taught before broad, so the
bare `except` habit never forms.

**Type the code, do not paste it.** Reading Python produces a strong feeling of
understanding that disappears the moment you face a blank file. The interpreter
is the only honest judge of whether you know something.

**Errors are the curriculum, not an interruption.** Module B09 is entirely about
reading them, and every module before it deliberately breaks something so you
meet the error in a safe place first.

**Finish Module B12.** A learner who has done eleven modules and no project
knows eleven topics. A learner who has finished the project can write programs.

## When you are ready to move on

You are ready for [Level 02 Intermediate](../02-intermediate/README.md) when you
can, without help:

- Write a program that reads a file, transforms the data, and writes a report.
- Choose between a list and a dictionary and say why.
- Write a function with parameters, a return value, and a type hint.
- Read a traceback and go straight to the line that matters.
- Create a virtual environment and install a package into it.

If any of those is shaky, the fix is a small program, not a re-read.
