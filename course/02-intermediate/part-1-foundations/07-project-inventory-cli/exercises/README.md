# Module 07 exercises

There are no separate exercises for this module. **The project is the
exercise.**

Build it in `~/projects/inventory-cli` (or anywhere outside this course
folder — treating it as a real project of your own is part of the point).

Track your progress against the eight stages and the definition-of-done
checklist in [`../README.md`](../README.md).

When you finish, come back and score yourself against the rubric. Then read
[`../solutions/`](../solutions/) — but not before Stage 5.
