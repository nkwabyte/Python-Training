# Level 02 — Intermediate

**Start here if you can already write a loop and a function, in Python or in any
other language.**

This is where Python stops being a syntax to learn and becomes a model to
understand. It answers the questions that separate people who use Python from
people who are trusted with it: what a name actually is, what happens at import
time, and why a class that looks correct still misbehaves under `==`.

## Coming from Level 01

Module 07 rebuilds the same kind of program you finished in Module B12, with
real structure, error design, and tests. Comparing the two is the fastest way
to see what this level is for.

Modules 02, 04, and 09 revisit ideas you met gently in the beginner track and
make them exact. Nothing you learned there becomes wrong; it becomes precise.

## When you are ready to move on

You are ready for [Level 03 Advanced](../03-advanced/README.md) when you can
explain aliasing with `id()`, design a class that behaves correctly under
`==`, `hash()`, iteration, `len()`, `in`, and `with`, and justify every dunder
you implemented.
