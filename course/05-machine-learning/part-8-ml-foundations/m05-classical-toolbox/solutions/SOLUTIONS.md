# Solutions & Commentary — Module M05: The Classical Toolbox

## Key Takeaways
- Decision Trees split on Gini impurity or Entropy; Random Forests aggregate randomized decision trees to reduce variance.
- Gradient Boosted Trees (XGBoost, LightGBM) train trees sequentially to correct residual errors.
- Unsupervised learning: K-Means for clustering; PCA for linear dimensionality reduction.
