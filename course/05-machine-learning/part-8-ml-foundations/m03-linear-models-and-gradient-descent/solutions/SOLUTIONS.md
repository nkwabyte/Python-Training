# Solutions & Commentary — Module M03: Linear Models & Gradient Descent

## Key Takeaways
- Linear Regression: MSE loss $J(w, b) = \frac{1}{N} \sum (\hat{y} - y)^2$.
- Logistic Regression: Binary Cross-Entropy loss with sigmoid activation $\sigma(z) = \frac{1}{1 + e^{-z}}$.
- Regularization: L1 (Lasso) produces sparse feature weights; L2 (Ridge) shrinks weights smoothly.
