# Solutions & Commentary — Module M02: The Maths You Will Actually Use

## Key Takeaways
- Matrix multiplication dimensions: $(M \times K) \cdot (K \times N) = (M \times N)$.
- Gradients represent the vector of partial derivatives pointing in the direction of steepest ascent.
- Micrograd scalar autograd engine computes gradients via reverse-mode automatic differentiation (chain rule).
