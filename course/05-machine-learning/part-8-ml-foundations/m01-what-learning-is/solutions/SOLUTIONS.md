# Solutions & Commentary — Module M01: What Learning Is

## Key Takeaways
- Frame ML problems precisely: Supervised (Classification/Regression), Unsupervised (Clustering/Dimensionality), or Reinforcement Learning.
- Prevent data leakage: Always split train/val/test splits BEFORE fitting scalers or imputing missing values.
- Diagnose underfitting (high bias) vs overfitting (high variance) using learning curves.
