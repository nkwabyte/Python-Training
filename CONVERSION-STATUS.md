# Notebook Conversion Status

Every exercise in the course is now a notebook. That was the structural half of
the work and it is done.

The second half is authoring the teaching cells to the standard in
`AUTHORING.md`, which cannot be automated, because the value of the format comes
from prose written for one specific idea. This file is the work list.

**Authored** means the notebook teaches every construct it asks for, contains a
deliberate failure that is explained, uses fill-in templates with `# ANSWER n`
markers, and ends with a named self-check. Module B01 is the reference.

**Lesson inlined** means the module's own concept sections were moved into the
notebook, before the tasks, with their code as runnable cells. The teaching is
real and was written for this course; what it has not had is a pass to shape it
to the exercise, add a deliberate failure, and turn the tasks into fill-in
templates.

**Converted** means the exercise content is intact and split into runnable
cells, but nothing in the notebook explains the concepts. These are the ones a
learner cannot learn from.
